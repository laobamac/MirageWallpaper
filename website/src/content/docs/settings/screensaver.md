「设置 → 屏保」用于安装、配置和管理 Mirage 的[动态屏保](/screensaver/overview/)。

## 屏保组件

- **安装 / 重新安装**：复制 `MirageScreenSaver.saver` 到当前用户的 `~/Library/Screen Savers/`。
- **卸载**：移除已安装的 `.saver`，不影响壁纸库。
- **打开系统屏保设置**：跳转到 macOS 设置；安装后仍需在那里选择 Mirage。

## 屏保壁纸

当前桌面壁纸为视频或场景时，「将正在播放的壁纸设为屏保」按钮可用。配置会保存预设、自定义属性、填充方式和帧率；屏保始终静音，帧率最高 60 FPS。网页壁纸和其他不支持类型不能配置为屏保。

屏保由独立宿主运行，不要求 Mirage 主程序保持运行；对同一壁纸的自定义修改会同步到屏保配置。

## 动态锁屏

- 方案 A 需要 macOS 26 或更高版本，使用未公开的系统 API，可能随系统更新失效。
- 方案 B 需要 macOS 14.2 或更高版本，依赖 Mirage 屏保组件和未公开的系统配置格式，解锁后恢复原桌面配置。
- 两种方案互斥，均只支持视频和场景壁纸。方案 B 在未签名开发构建中可能要求完全磁盘访问权限。
