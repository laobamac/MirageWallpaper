---
title: 动态屏保
description: 把视频或场景壁纸设为 macOS 屏保，独立于 Mirage 主程序运行。
---

Mirage 提供独立的动态屏保组件。当前「设置 → 屏保」可以把**视频或场景壁纸**设为屏保；网页壁纸不能配置为屏保。

![Mirage 动态屏保设置](/images/docs/settings-screensaver.webp)

## 安装

1. 打开「设置 → 屏保」，点击「安装」。组件会复制到当前用户的 `~/Library/Screen Savers/MirageScreenSaver.saver`。
2. 点击「打开系统屏保设置」，在 macOS 系统设置中选择 Mirage。

更新 Mirage.app 后，已复制到用户目录的屏保不会自动同步；需要时点击「重新安装」。卸载只移除 `.saver`，不会删除壁纸库。

## 选择壁纸

「将正在播放的壁纸设为屏保」会保存当前视频或场景壁纸的预设、自定义属性、填充方式和帧率。屏保始终静音，帧率最高为 60 FPS；对同一壁纸的自定义修改会同步到屏保配置。屏保宿主独立运行，不要求 Mirage 主程序保持打开。

## 动态锁屏

屏保设置还提供两套实验性动态锁屏方案，二者不能同时启用：

- **方案 A**：仅 macOS 26 或更高版本可用，使用未公开的系统 API；启用前需要在确认窗口输入「我同意」或 `Agree`，并按提示前往系统墙纸设置选择 Mirage。
- **方案 B**：macOS 14.2 或更高版本可用，通过已安装的 Mirage 屏保临时接管锁屏期间的墙纸槽位，解锁后恢复原桌面配置；同样依赖未公开的系统配置格式。

两套方案都只支持视频和场景壁纸，可能随 macOS 更新失效。当前未使用开发者证书签名时，方案 B 可能要求在「隐私与安全性 → 完全磁盘访问权限」中启用 Mirage。
